🧠 My Thought-Clone AI

「完全オフライン環境で稼働する、自己思考・哲学の移植を目的としたローカルAIエージェント」

📝 プロジェクト概要

本プロジェクトは、外部のクラウドAPI（OpenAIやAnthropicなど）に依存せず、自分自身の思考プロセスや独自のコンテキスト（哲学・価値観）をローカルLLMに移植し、シミュレーションすることを目的とした実験的AIエージェントです。

最大のテーマは**「データ主権（Data Sovereignty）の確立」**です。
個人の深い思考ログやプライベートなコンテキストを扱うため、データを一切外部サーバーへ送信せず、ローカルハードウェア（Apple Silicon Mac）上で安全に完結するアーキテクチャを採用しています。

✨ 設計思想とコア機能

• 🛡️ 究極のプライバシーとデータ主権
Ollamaをバックエンドとして採用し、推論処理をすべてローカル環境で実行。通信監査ツールを用いても外部へのデータ流出（Egress Traffic）がゼロであることを前提とした、セキュアな主権開発環境です。

• 🗂️ 思考コンテキストの外部注入 (RAG / プロンプトエンジニアリング)
ベースとなるLLMに対し、独自の思考パターンや定義ファイルを読み込ませることで、一般的なAIの優等生的な回答ではなく、自身の論理構造に基づいた自律的なアウトプットを生成します。



> 🔒 セキュリティノート:
本リポジトリの data/ ディレクトリには構造を示すサンプルファイルのみを格納しています。実際の運用で使用している個人的な思考データやログは、プライバシー保護の観点からコミットしていません。
